# vpnctl

[English](README.md) · [简体中文](README.zh-CN.md) · **Русский** · [فارسی](README.fa.md)

Свой прокси на чистом VPS: одна команда, веб-панель, без ручной правки конфигов.
Открытый код, без аналитики. Данные доступа генерируются на вашем сервере.

**[Релиз v0.3.0](https://github.com/MolodoyArtist/asterisk/releases/tag/v0.3.0)**

## Установить

Нужен **чистый VPS с Ubuntu 22.04 или 24.04**: публичный IPv4, x86_64 или arm64,
от 512 МиБ памяти и 2 ГиБ свободного места. Установщик настраивает Nginx, UFW и
systemd — используйте сервер, на котором нет других сервисов.

Подключитесь к VPS по SSH и вставьте:

```bash
curl -fsSL https://github.com/MolodoyArtist/asterisk/releases/latest/download/install.sh | sudo bash
```

Ответьте, есть ли у вас домен. Сохраните адрес панели, логин, пароль,
ссылку подключения и QR-код, которые появятся в конце.

## Подключиться

**Без домена:** войдите на `https://SERVER_IP:9443`, откройте **Devices** и
импортируйте ссылку или QR-код VLESS + REALITY + Vision в совместимый клиент.

**С доменом:** войдите на `https://YOUR_DOMAIN:9443` и откройте **Devices**:

| Профиль | Клиент | Импорт |
| --- | --- | --- |
| VLESS + XHTTP + TLS | Клиент на базе Xray, например v2RayTun | Ссылка, QR или Xray JSON |
| Hysteria 2 | sing-box 1.12+ | JSON-файл |

XHTTP JSON создаёт локальный SOCKS-прокси; туннелем управляет графический клиент.
Обычный sing-box не поддерживает этот XHTTP-профиль. Добавляйте отдельное устройство
для каждого телефона или компьютера; удаление устройства отзывает его доступ.

## Добавить домен позже

1. Направьте **A-запись** домена на IP вашего VPS. В Cloudflare выберите **DNS only**.
   AAAA-запись добавляйте только при работающем публичном IPv6 на VPS.
2. В панели: **Domain → Check DNS → Activate XHTTP and Hysteria**.
3. REALITY перестанет работать. Отключите его, войдите на `https://YOUR_DOMAIN:9443`
   и скачайте новые профили из **Devices**.

Nginx отдаёт сайт для маскировки и передаёт запросы по случайно сгенерированному пути
XHTTP в Xray на `127.0.0.1:5555`. Hysteria принимает QUIC напрямую.
Сертификаты продлеваются автоматически. Домен не гарантирует обход DPI или блокировки IP.

## Опционально: Telegram

После активации домена нажмите **Telegram → Enable Telegram proxy** и откройте
полученную ссылку в Telegram. Используется **mtg + FakeTLS** с маскировкой под ваш
сайт, для сообщений и медиа. Для трафика звонков может понадобиться VPN.

## Порты

Разрешите их в фаерволе провайдера VPS. Правила UFW на сервере настроит vpnctl.

| Порт | Назначение |
| --- | --- |
| Ваш порт SSH | Доступ к серверу |
| 80/TCP | Проверка сертификатов |
| 443/TCP | REALITY, после активации домена — Nginx + XHTTP |
| 9443/TCP | Веб-панель |
| 443/UDP | Hysteria после активации домена |
| 8443/TCP | Telegram, только если включён |

**5555 доступен только локально.** Через сайт для маскировки попасть в панель нельзя.

## Обновление и помощь

Выполните ту же команду установки для обновления до последнего опубликованного релиза.
Обновление проверяет настройки и при ошибке пытается откатить изменения.
Старые установки сохраняют ссылки до явной активации новой доменной схемы.
Перед обновлением отключите старый Telegram/padding-профиль.

```bash
sudo vpnctl doctor                 # Проверить службы и сертификаты
sudo vpnctl admin reset-password   # Сбросить пароль панели
```

Если панель не открывается, сначала проверьте фаервол провайдера и DNS.
Удалите `/root/vpnctl-install.json`, когда надёжно сохраните начальные данные доступа.
Не публикуйте JSON-профили, ссылки подключения и серверные логи.

CI проверяет Ubuntu 22.04/24.04, конфиги, маскировку FakeTLS, обновление и откат.
Полная установка на отдельный чистый VPS ещё не проверена.
