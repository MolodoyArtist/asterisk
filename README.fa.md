# vpnctl

[English](README.md) · [简体中文](README.zh-CN.md) · [Русский](README.ru.md) · **فارسی**

<div dir="rtl">

پروکسی شخصی روی یک VPS تازه: یک دستور، پنل وب و بدون ویرایش دستی تنظیمات.
کد پروژه باز است و داده‌های تحلیلی جمع‌آوری نمی‌شود. اطلاعات دسترسی روی سرور خودتان ساخته می‌شود.

**[نسخهٔ v0.3.0](https://github.com/MolodoyArtist/asterisk/releases/tag/v0.3.0)**

## نصب

یک **VPS تازه با Ubuntu 22.04 یا 24.04** لازم دارید: IPv4 عمومی، معماری x86_64 یا arm64،
حداقل ۵۱۲ مگابایت حافظه و ۲ گیگابایت فضای آزاد. نصب‌کننده Nginx، UFW و systemd را تنظیم می‌کند؛
از سروری استفاده کنید که سرویس دیگری روی آن اجرا نمی‌شود.

با SSH به VPS وصل شوید و این دستور را وارد کنید:

<div dir="ltr">

```bash
curl -fsSL https://github.com/MolodoyArtist/asterisk/releases/latest/download/install.sh | sudo bash
```

</div>

مشخص کنید که آیا دامنه دارید. آدرس پنل، نام کاربری، گذرواژه، لینک اتصال و کد QR پایان نصب را در جایی امن نگه دارید.

## اتصال

**بدون دامنه:** وارد `https://SERVER_IP:9443` شوید و **Devices** را باز کنید.
لینک یا کد QR مربوط به VLESS + REALITY + Vision را در یک کلاینت سازگار وارد کنید.

**با دامنه:** وارد `https://YOUR_DOMAIN:9443` شوید و **Devices** را باز کنید:

| پروفایل | کلاینت | روش وارد کردن |
| --- | --- | --- |
| VLESS + XHTTP + TLS | کلاینت مبتنی بر Xray، مانند v2RayTun | لینک، QR یا JSON مخصوص Xray |
| Hysteria 2 | sing-box 1.12+ | فایل JSON |

فایل JSON مربوط به XHTTP یک پروکسی SOCKS محلی ایجاد می‌کند؛ برنامهٔ گرافیکی تونل را مدیریت می‌کند.
نسخهٔ اصلی sing-box از این پروفایل XHTTP پشتیبانی نمی‌کند.
برای هر گوشی یا رایانه یک دستگاه جدا اضافه کنید؛ حذف دستگاه، دسترسی آن را لغو می‌کند.

## افزودن دامنه در آینده

۱. **رکورد A** دامنه را به IP سرور وصل کنید. در Cloudflare حالت **DNS only** را انتخاب کنید.
رکورد AAAA را فقط زمانی اضافه کنید که IPv6 عمومی سرور درست کار می‌کند.

۲. در پنل به **Domain → Check DNS → Activate XHTTP and Hysteria** بروید.

۳. REALITY متوقف می‌شود. اتصال آن را قطع کنید، وارد `https://YOUR_DOMAIN:9443` شوید
و پروفایل‌های جدید را از **Devices** دریافت کنید.

Nginx یک سایت پوششی نمایش می‌دهد و درخواست‌های مسیر تصادفی XHTTP را به Xray در
`127.0.0.1:5555` می‌فرستد. Hysteria مستقیماً QUIC را دریافت می‌کند. گواهی‌ها خودکار تمدید می‌شوند.
دامنه تضمینی برای عبور از DPI یا مسدود نشدن IP نیست.

## پروکسی اختیاری تلگرام

پس از فعال‌سازی دامنه، **Telegram → Enable Telegram proxy** را انتخاب کنید و لینک را در تلگرام باز کنید.
این قابلیت از **mtg + FakeTLS** با سایت شما به‌عنوان پوشش برای پیام و رسانه استفاده می‌کند.
ترافیک تماس ممکن است همچنان به VPN نیاز داشته باشد.

## پورت‌ها

این پورت‌ها را در فایروال ارائه‌دهندهٔ VPS باز کنید. vpnctl قوانین UFW روی سرور را مدیریت می‌کند.

| پورت | کاربرد |
| --- | --- |
| پورت SSH شما | دسترسی به سرور |
| 80/TCP | اعتبارسنجی گواهی |
| 443/TCP | ابتدا REALITY؛ پس از فعال‌سازی دامنه Nginx + XHTTP |
| 9443/TCP | پنل وب |
| 443/UDP | Hysteria پس از فعال‌سازی دامنه |
| 8443/TCP | تلگرام، فقط در صورت فعال بودن |

**پورت 5555 فقط محلی است.** سایت پوششی مسیری به پنل ندارد.

## به‌روزرسانی و راهنما

برای به‌روزرسانی به آخرین نسخهٔ منتشرشده، همان دستور نصب را دوباره اجرا کنید.
تنظیمات بررسی می‌شوند و در صورت خطا، نصب‌کننده تلاش می‌کند وضعیت قبلی را برگرداند.
لینک‌های نصب‌های قدیمی تا فعال‌سازی صریح روش جدید حفظ می‌شوند.
پیش از ارتقا، پروفایل قدیمی Telegram/padding را غیرفعال کنید.

<div dir="ltr">

```bash
sudo vpnctl doctor
sudo vpnctl admin reset-password
```

</div>

دستور اول سرویس‌ها و گواهی‌ها را بررسی می‌کند؛ دستور دوم گذرواژهٔ پنل را بازنشانی می‌کند.
اگر پنل باز نمی‌شود، ابتدا فایروال ارائه‌دهنده و DNS را بررسی کنید.
پس از نگهداری امن اطلاعات دسترسی اولیه، `/root/vpnctl-install.json` را حذف کنید.
فایل‌های JSON، لینک‌های اتصال و گزارش‌های سرور را عمومی نکنید.

آزمون‌های CI شامل Ubuntu 22.04/24.04، تنظیمات، پوشش FakeTLS، به‌روزرسانی و بازگشت به نسخهٔ قبلی هستند.
نصب کامل روی یک VPS تازه و جداگانه هنوز تأیید نشده است.
